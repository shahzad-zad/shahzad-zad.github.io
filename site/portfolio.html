Scientific ML

Physics-Constrained ML for CNT Chirality Prediction

Latent-structure models for controllable CNT chirality prediction.

Python · Mixture Models · Physics Constraints · Inverse Design
Read about this project

Developed a physics-constrained latent-structure framework that models hidden chirality distributions instead of relying on black-box correlations.

Problem Framing

Directly predicting CNT properties from synthesis parameters often hides the underlying chirality structure. This project instead models the latent chirality distribution itself, which makes the predictions more aligned with the underlying physics of the process.

Model Design

The framework uses mixture-style latent representations constrained by domain knowledge. These constraints prevent physically implausible solutions and make the learned relationships more robust than pure black-box regression.

Why It Matters

The resulting model offers interpretable signals about chirality shifts under different conditions. That makes it useful not only for prediction, but for synthesis planning where controllability is more important than benchmark accuracy alone.

Outcomes

Improved predictive reliability and generated interpretable chirality-shift insights for controllable CNT synthesis.

Aerosol CVD

Master's Thesis: CNT Synthesis Optimization

Optimising reactor parameters for controllable CNT structure and performance.

COMSOL Multiphysics · Aerosol CVD · Machine Learning · Raman Spectroscopy
Read about this project

An MSc thesis integrating aerosol CVD experiments, COMSOL CFD, and machine learning to connect reactor conditions with chirality-resolved CNT properties.

Research Goal

This thesis focuses on controlling the structural and functional properties of carbon nanotubes synthesised through aerosol chemical vapor deposition. The work combines laboratory process optimisation with computational models so reactor design decisions can be tied to measurable CNT outcomes.

Methodology

The project uses COMSOL simulations to resolve thermal fields, velocity profiles, and precursor decomposition under changing process conditions. Those simulation outputs are paired with experimental measurements and chirality-aware data analysis to understand how the reactor environment shapes the final nanotube population.

Impact

The result is a stronger inverse-design foundation for CNT synthesis. Instead of tuning conditions by trial and error alone, the workflow supports data-driven decisions about reactor parameters and provides a path toward more reproducible CNT quality.

Outcomes

Built a workflow spanning thermal-field simulation, precursor decomposition analysis, and inverse-design-ready chirality modelling.

CFD Modelling

Hydrogen and Injector Depth Effects in Aerosol CVD

COMSOL study of hydrogen fraction and injector depth in CNT growth.

COMSOL Multiphysics · Heat Transfer · Fluid Flow · Reaction Engineering
Read about this project

Investigated how hydrogen concentration and injector depth reshape thermal fields, velocity profiles, reaction rates, and precursor decomposition in an aerosol CVD reactor.

Simulation Scope

This study examines how hydrogen concentration and injector depth alter conditions inside the aerosol CVD reactor. The emphasis is on how the gas mixture and geometry affect heating, flow stability, and catalyst behaviour before CNT formation takes place.

Key Observations

The simulations identified strong changes in recirculation zones, gas preheating, and decomposition points. These effects directly influence catalyst residence time and therefore the structural metrics that matter in downstream CNT characterisation.

Engineering Use

The project gives reactor designers a more defensible basis for adjusting injector placement and hydrogen fraction. Rather than relying on intuition, the analysis quantifies which settings improve uniformity and which settings destabilise the process window.

Outcomes

Mapped recirculation and preheating effects that influence catalyst residence time, defect density, and CNT uniformity.

Process Optimisation

Data-efficient ML for Aerosol CVD CNT Synthesis

Predicting CNT yield, R90, and G/D ratio with fewer experiments.

Python · scikit-learn · SHAP · Experimental Design
Read about this project

Built a machine-learning pipeline that links precursor feed rates, ethylene concentration, and temperature to CNT synthesis outcomes while keeping model performance strong on smaller datasets.

Motivation

CNT experiments are expensive and time-consuming, so reducing the number of trials matters. This project explores how far predictive modelling can go when the available training data is intentionally limited.

Pipeline

The model maps process variables such as precursor feed rates, ethylene concentration, and temperature to output metrics like yield, R90, and G/D ratio. Feature-importance analysis and SHAP were used to explain which variables dominate the process-property relationship.

Result

The study showed that predictive performance remains useful even after a large reduction in training size. That makes the approach practical for experimental programmes where each run has high cost and turnaround time.

Outcomes

Maintained strong predictive performance with roughly 50% less training data and used SHAP to guide process optimisation.

Thermal-Fluid Systems

Geometry Optimization of a Compact Cyclone Separator

Compact separator design for 1-2 um Fe2O3 particle capture.

COMSOL Multiphysics · Particle Tracing · Turbulence Modelling
Read about this project

Designed and evaluated a compact Lapple-type cyclone separator for CVD exhaust treatment, balancing turbulent flow behaviour, particle trajectories, and pressure drop.

Design Target

The separator was designed for compact deployment while still capturing fine Fe2O3 particles from CVD exhaust streams. This created a practical tradeoff between footprint, efficiency, and energy cost.

Analysis

The work models turbulent flow and particle trajectories to estimate how small geometry changes affect separation efficiency. Pressure-drop penalties were evaluated alongside capture improvements so the final recommendation stayed grounded in realistic operating constraints.

Outcome

The optimisation indicated a measurable gain in fine-particle separation without drifting into impractical geometry. That makes the project relevant for cleaner, more controllable reactor exhaust handling.

Outcomes

Estimated 18-25% improvement in fine-particle separation efficiency after geometry optimisation.

Multimodal ML

Multimodal LLM/VLM Models for Optical Property Prediction

Hybrid LLM, VLM, and XGBoost models for thin-film optics.

Python · XGBoost · LLM · VLM
Read about this project

Developed multimodal pipelines combining language and vision models with gradient boosting to predict optical transmittance and direct bandgap from thin-film data.

Concept

This project explores whether multimodal models can improve thin-film optical property prediction by combining visual and text-derived signals with structured machine-learning features.

Implementation

Vision-language and language-model embeddings were fused with XGBoost to predict direct bandgap and transmittance. The evaluation used group-aware validation to avoid leakage and make the reported performance more credible.

Takeaway

The strongest gains appeared in optical transmittance prediction, while direct bandgap remained harder. Even so, the project shows that multimodal fusion can materially improve property prediction when the validation protocol is handled carefully.

Outcomes

Reached R^2 ~ 0.963 for transmittance and R^2 ~ 0.788 for direct bandgap using leakage-aware validation.

Geoscience ML

Prediction of Thermal Properties of Igneous Rocks

Regression models for geological thermal-property prediction.

MATLAB · Genetic Algorithm · PSO · SHAP
Read about this project

A research-assistant project focused on consolidating geoscientific datasets, training multiple regressors, and interpreting the elemental drivers behind thermal-property variation.

Dataset Work

The project brought together multi-source geoscientific data and converted it into a supervised-learning workflow for thermal-property prediction. That data engineering step was essential because model quality depended heavily on consistent feature representation.

Modeling Strategy

More than eight regression approaches were trained and compared, with hyperparameter optimisation driven by GA and PSO. SHAP and sensitivity analysis were used to interpret the physical meaning behind the predictions rather than treating the output as a closed box.

Research Output

The outcome was both technical and publication-oriented: strong predictive performance on held-out data and an under-review manuscript focused on sensitivity and uncertainty quantification.

Outcomes

Achieved R^2 > 0.90 on test data and produced an under-review manuscript on sensitivity and uncertainty analysis.
